# knowledge-base-app

## Project name
knowledge-base-app

## Year
2026

## Purpose
Full-stack knowledge base app to create, search, and manage articles with secure authentication.

## Features
- User signup and login with JWT-protected routes
- Create, edit, and delete articles (title, description, content, tags)
- Dashboard listing and individual article views
- Search by title or description
- Server-side pagination with MongoDB
- Responsive UI with toast feedback

## Tech Stack used
- Next.js
- React
- TypeScript
- Tailwind CSS
- Express
- Mongoose
